agentsys
GitHub · Changelog · Docs

Verified handoff across AI coding tools

agentsys is a zero-dependency coordination layer (Python 3.9+, SQLite, git) so multiple agents share one task store. Nothing ships until automated checks pass, an independent identity reviews, and a human approves merge.

export PATH="$HOME/agentsys/bin:$PATH"
export AGENTSYS_ACTOR=human:you
agentsys init
AGENTSYS_DEMO=1 agentsys demo --force

Isolated worktrees

Implement tasks run on agent branches with path scopes; overlapping work is refused.

Audit you can verify

Hash-chained events and agentsys verify-log — local file, not cloud telemetry.

Honest budgets

Per-provider accounts, never pooled. Dispatch is refused when caps would be exceeded.

Live dashboard

agentsys ui shows flow, runs, spend, and the exact CLI to run next.
